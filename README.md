# NFTMarket

Turns cryptocurrency trading data into JSON-compatible formats for integration with web applications and data analytics tools.

With NFTMarket, you get a lightweight tool that stays out of your way.

**What you get**

- Turns cryptocurrency trading data into
- JSON-compatible formats for integration with
- web applications and data analytics

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/centxyz/NFTMarket.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
